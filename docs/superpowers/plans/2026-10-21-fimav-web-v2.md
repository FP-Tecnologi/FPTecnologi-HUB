# Fimav web v2 (identidad hexagonal, Perú Compras, marcas y movimiento) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Llevar `apps/fimav-web` más cerca del brochure: títulos con la tipografía del brochure, formas hexagonales de esquinas redondeadas (fotos, botones, botón de chat, bordes de sección), página y sección de Perú Compras con su logo, logos de marcas y un sitio con movimiento (hero, entradas/salidas, hover, cursor).

**Architecture:** Primitivas hexagonales reutilizables en `src/components/hex/` (ruta SVG con vértices redondeados, marco de imagen, botón); efectos de movimiento con CSS + un par de componentes cliente pequeños (`Reveal`, `HaloCursor`, `Inclinar`), sin dependencias nuevas. Todo respeta `prefers-reduced-motion` y funciona sin JavaScript.

**Tech Stack:** Next 16, Tailwind 4, lucide-react, `next/font/google` (Source Sans 3 para títulos), PyMuPDF para extraer activos del brochure.

**Spec:** pedidos del usuario en el chat del 2026-10-21 (sobre `docs/superpowers/specs/2026-10-21-fimav-web-design.md`, que sigue vigente salvo lo que aquí se cambia).

## Global Constraints

- Solo modo claro; paleta única: rojo `#E02424`, rojo profundo `#C02020`, botón `#C91F1F` (texto blanco), carbón `#38383C`, tinta `#111`, gris `#F3F3F4`, plata (degradado sampleado del logo), blanco. Texto rojo pequeño sobre claro = `text-rojo-hondo`; texto pequeño sobre rojo = `bg-boton` + `text-white`; nada de texto rojo sobre carbón; foco `focus-visible:outline-white` sobre carbón.
- **Esquinas**: toda forma hexagonal tiene vértices REDONDEADOS (como el hexágono de la portada del brochure), nunca puntas filosas. Aplica a fotos, botones, botón de chat/WhatsApp, iconos y recortes de sección.
- **Títulos**: tipografía humanista tipo Myriad del brochure → Source Sans 3 (regular/semibold), en dos tonos carbón + rojo (`Titulo`). Texto de párrafo sigue en Poppins.
- Accesibilidad: foco visible que siga la forma (no depender de `outline` sobre `clip-path`), contraste AA, objetivos ≥44px, `aria-hidden` en lo decorativo, un h1 por página, animaciones desactivadas con `prefers-reduced-motion` y contenido visible sin JavaScript (la clase que oculta para animar solo se aplica con JS activo).
- Rendimiento: animar solo `transform`/`opacity`; sin librerías nuevas; imágenes con `loading="lazy"` bajo el pliegue y dimensiones/aspect para evitar saltos.
- Logos de terceros (Perú Compras, marcas): solo para indicar presencia/alianza, tal como el brochure; no alterar sus colores salvo el blanco sobre rojo del brochure.
- Verificación por tarea: `npm run lint` (tsc), `npm run build` (reiniciar el dev server después), capturas a 1280 y 375, sin scroll horizontal, 1 h1 por página.
- Commits en español terminando con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. No subir `.env*` ni `apps/quamtu-web/.impeccable/`.

### Task 1: Sistema hexagonal redondeado y tipografía de títulos

**Files:** Create `components/hex/*`; Modify `layout.tsx`, `globals.css`, `Titulo.tsx`, `Hexagono.tsx`, `Header.tsx`, `MenuMovil.tsx`, `Footer.tsx`, `WhatsAppFlotante.tsx`, `home/*`, `app/nosotros/page.tsx`, `app/catalogo/**`, `FormCotizar.tsx`, `FormReclamacion.tsx`, cualquier otro botón/imagen/recorte.

**Interfaces — Produces:**
- `rutaHexagono(opts: { orientacion: 'punta-arriba' | 'punta-lado'; radio: number }): string` → path SVG en coordenadas de `objectBoundingBox` (0–1) con los 6 vértices redondeados con curvas (radio relativo, ~0.08).
- `<HexImagen src alt className? orientacion? sizes? />` → foto recortada por un `clipPath` redondeado (SVG `clipPathUnits="objectBoundingBox"`, id único con `useId`), con `aspect-[1/1.1]` y `loading="lazy"`.
- `<BotonHex href? onClick? type? variante: 'rojo' | 'carbon' | 'contorno' size: 'md' | 'lg' disabled? children />` → enlace (`next/link`) o `<button>`; forma de hexágono alargado (vértices izquierdo/derecho redondeados) construida de forma robusta a cualquier ancho (dos tapas SVG de la altura del botón + cuerpo central, o SVG de fondo con la ruta calculada según el ancho); foco visible que sigue la forma (anillo dibujado en el SVG con `focus-visible`, no `outline` sobre `clip-path`); texto blanco sobre `bg-boton`.
- `<CorteHex lado: 'arriba' | 'abajo' color />` → borde de sección con muescas hexagonales redondeadas (reemplaza las curvas `rounded-l-[6rem]` y los chevrones filosos del pie y CtaCotizar).

# Web pública Fimav Perú Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publicar `apps/fimav-web`, la web corporativa de Fimav Perú (home, nosotros, catálogo por categorías, cotizador, contacto, legales) con identidad tomada del logo y del brochure, solo modo claro.

**Architecture:** App Next 16 independiente (como `apps/quamtu-web`, sin three/gsap). Contenido fijo en `src/lib/*.ts`; ilustraciones como componentes SVG; el formulario de cotización pasa por un proxy `/api/hub/cotizador` hacia `POST /public/cotizador/leads?marcaId=…` de la API del HUB. No se toca la API.

**Tech Stack:** Next 16 (webpack build), React 19, Tailwind 4, lucide-react, TypeScript 5.9. Extracción de imágenes con PyMuPDF (ya instalado).

**Spec:** `docs/superpowers/specs/2026-10-21-fimav-web-design.md`

## Global Constraints

- Solo modo claro; sin selector de tema ni `prefers-color-scheme` oscuro.
- Paleta única: rojo `#E02424`, rojo profundo `#C02020`, botón con texto blanco `#C91F1F` (≥4.5:1), carbón `#38383C`, tinta `#111111`, gris claro `#F3F3F4`, plata (degradado `#F1F1F2`→`#8E8F93`), blanco. Ningún otro color.
- Tipografía: Poppins (400/500/600/700). Títulos en dos tonos: carbón + rojo.
- Logo: el del brochure/entregado, sin redibujar (`public/brand/logo.png`).
- Datos: Jr. Huaraz 1833, Breña, Lima · tel. 01 397-9527 · ventas@fimavperu.com · comercial@fimavperu.com.
- Nombres de negocio en español; técnicos internos en inglés. Puerto de desarrollo **3005**.
- Un solo marcaId por env `HUB_MARCA_ID`; sin él, `/api/hub/cotizador` responde 503 y el formulario cae a WhatsApp/correo.
- Verificación por tarea: `npm run lint` (tsc) dentro de `apps/fimav-web`; visual en navegador (escritorio 1280 y móvil 375). No hay runner de tests en las webs; no se agrega uno.
- Commits en español, terminan con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Nunca subir `envs/`.

- [ ] **Step 1: Escribir el script** (ejecutar con `python -I extraer.py`; PDF de `C:/Users/Jaime Tarazona/Downloads/brochure fimav peru 2023.pdf`, salida `apps/fimav-web/public`):
```python
import pymupdf, pathlib
PDF = r"C:/Users/Jaime Tarazona/Downloads/brochure fimav peru 2023.pdf"
OUT = pathlib.Path(r"C:/Users/Jaime Tarazona/Documents/GitHub/FPTecnologi-HUB/apps/fimav-web/public")
(OUT/"fotos").mkdir(parents=True, exist_ok=True); (OUT/"brand").mkdir(parents=True, exist_ok=True)
doc = pymupdf.open(PDF)

def guardar(xref, destino):
    pix = pymupdf.Pixmap(doc, xref)
    if pix.alpha or pix.n >= 5: pix = pymupdf.Pixmap(pymupdf.csRGB, pix)
    while pix.width > 1200: pix.shrink(1)   # mitad por vuelta
    pix.save(str(destino), jpg_quality=82)

# páginas 5-9 (índices 4-8): arriba 3 fotos, abajo 3 fotos
ORDEN = {4: ("escritorios", "all-in-one"), 5: ("monitores", "proyectores"), 6: ("impresoras", "aire"),
         7: ("servidores", "consumibles"), 8: ("networking", "mobiliario")}
for p, (arriba, abajo) in ORDEN.items():
    infos = [i for i in doc[p].get_image_info(xrefs=True) if i["xref"] and i["bbox"][2]-i["bbox"][0] > 100]
    infos.sort(key=lambda i: (0 if i["bbox"][1] < 300 else 1, i["bbox"][0]))
    for k, i in enumerate(infos[:6]):
        guardar(i["xref"], OUT/"fotos"/f"{arriba if k < 3 else abajo}-{k % 3 + 1}.jpg")

# foto más grande de las páginas 2 (nosotros) y 4 (por qué escogernos)
for p, nombre in ((1, "nosotros"), (3, "escogernos")):
    mayor = max((i for i in doc[p].get_image_info(xrefs=True) if i["xref"]), key=lambda i: i["width"]*i["height"])
    guardar(mayor["xref"], OUT/"fotos"/f"{nombre}.jpg")

# logo: recorte de la última página (índice 11), a 6x
pg = doc[11]
pix = pg.get_pixmap(matrix=pymupdf.Matrix(6, 6), clip=pymupdf.Rect(40, 205, 260, 305))
pix.save(str(OUT/"brand"/"logo.png"))
pix2 = pg.get_pixmap(matrix=pymupdf.Matrix(2, 2), clip=pymupdf.Rect(40, 205, 125, 305))  # solo la espiral
pix2.save(str(OUT.parent/"src"/"app"/"icon.png"))
```

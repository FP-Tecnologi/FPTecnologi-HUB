# CMS de la web de Fimav Perú en el administrador — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Pedido (2026-10-23):** que cada página de fimavperu.com se pueda editar desde el administrador, "con sus marcas y sus
limitaciones, como se está haciendo en el admin".

## Estado actual

- **FPTecnologi** ya tiene CMS: `ContenidoWeb` (marca + página + sección → JSON) en la API (`/contenido/:pagina`,
  `PUT /contenido/:pagina/:seccion`, público `GET /public/contenido/:pagina?marcaId`). El dashboard usa un editor
  genérico (`CmsEditor` en `WebHomeCms.tsx`) configurado por página: lee el contenido actual de la web
  (`{web}/api/cms/:pagina` = defaults + lo guardado), guarda en la API y muestra la web en un iframe.
- **Fimav** tiene todo fijo en el código: `src/lib/contenido.ts` (textos), `contacto.ts` (datos), `categorias.ts`,
  `legal.ts`, el slider del inicio y los banners de cada página.
- **Menú por marca**: solo Quamtu tiene recorte (`soloQuamtu` en `Sidebar.tsx`); Fimav ve hoy TODOS los módulos de
  FPTecnologi (web, tienda, chat, blog…), aunque su web no usa ninguno.

## Decisiones

- **Mismo modelo y misma API**: `ContenidoWeb` con el `marcaId` de Fimav; no hay migración ni endpoint nuevo.
  Páginas: `inicio`, `nosotros`, `catalogo`, `peru-compras`, `contacto`, `cotizar`, `ajustes`, `legal`.
- **Los defaults viven en la web de Fimav** (`src/lib/cms.ts`, a partir del contenido fijo de hoy): sin nada
  guardado, la web se ve igual que ahora; si la API no responde, también.
- **Editor**: se reusa `CmsEditor` con una URL de web por marca (`NEXT_PUBLIC_WEB_FIMAV_URL`) y dos tipos de campo
  nuevos: `imagen` (URL + subir) y `lista-objetos` (lista con subcampos; `fijo` = sin agregar/quitar, para las
  categorías, cuyo slug e ícono no se editan porque son URLs y el formulario de cotizar los usa).
- **Límites por marca** (`MODULOS_POR_MARCA` en el menú, generaliza `soloQuamtu`): Fimav ve solo *Web Fimav*,
  *Cotizador → Leads*, *Herramientas → Contactos*, *Libro de reclamaciones* y *Equipo*. Los nodos de *Web Fimav*
  llevan `marcas: ["fimav"]` y no aparecen en las otras marcas. Las pantallas de Fimav avisan si la marca activa no
  es Fimav. Roles: los de siempre (`marketing`; `admin` ve todo).
- **Vista previa al instante**: la web de Fimav lee el CMS en cada visita (sin caché, deduplicado por petición y con
  `connection()` para no quedar prerenderizada en el build), igual que la web de FPTecnologi. Se descartó la caché de 30 s
  porque la vista previa del editor mostraría lo anterior al guardar.
